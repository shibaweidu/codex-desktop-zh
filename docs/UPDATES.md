# Codex 下载与自动更新说明

工具中有两种更新，目标和来源不同：

| 操作 | 更新什么 | 来源 |
|---|---|---|
| 设置与关于 > 检查更新 | Codex 汉化增强工具自身 | 本仓库 GitHub Releases |
| 下载 Codex | OpenAI Codex Desktop 客户端 | Wangnov 社区镜像 |

## 汉化工具自身更新

启动检查或手动检查发现新版后，由用户确认，工具下载对应平台文件及同版 `SHA256SUMS.txt`，校验后由独立辅助进程备份旧程序、覆盖并重启。更新不关闭 Codex。

macOS 更新无需付费开发者账号即可实现，但 ad-hoc 签名不能提供苹果认可的发布者身份，Gatekeeper 仍可能阻止首次打开或更新后重启。目录不可写、校验或替换失败时查看错误并使用 Release 手动更新入口。

## Codex 客户端更新

使用 [社区镜像项目](https://github.com/Wangnov/codex-app-mirror) 提供的版本与下载信息。这是社区分发渠道，与本工具及 OpenAI 官方网站不是同一来源。

Windows 比较本机 MSIX 包版本；已有相同或更高版本时跳过下载。有新版时优先直连镜像，失败后切换入口，支持暂停续传与已校验缓存。安装前验证大小、哈希、签名、发布者与包身份；确认后为当前账户部署，并复核注册版本。请先退出 Codex。便携版通过原安装渠道更新。

macOS 比较应用版本与构建号，校验哈希、Apple 签名、Team ID、Bundle ID 和架构，确认后替换并重启 Codex.app。系统目录可能触发 macOS 授权。

## 下载慢、断线或安装失败

暂停后重试可以保留符合条件的下载进度；哈希不匹配的数据不能复用。下载完成并不代表系统部署完成，日志应包含 Windows 返回码或 Mac 替换结果。错误详情与排查步骤见 [故障排查](TROUBLESHOOTING.md)。

仅汉化不会替换 Codex 安装文件；用户确认客户端更新后，才会部署或替换对应客户端。Codex 更新若改变内部设置接口或菜单，本工具也可能需要兼容更新。
