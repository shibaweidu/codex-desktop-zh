# Codex 汉化失败、菜单英文与更新失败排查

## “汉化未完全生效”是什么意思？

它表示本次验证没有全部通过，不等于安装损坏。先看日志中的两部分：

| 详情 | 如何判断 |
|---|---|
| `locale.detail` / `verification` | 设置接口结果与实际可见控件的语言检测 |
| `menu.detail` | 菜单来源、检查数量、未覆盖标签或接口连接错误 |

`untranslated` 有具体英文条目时才说明发现未收录菜单；接口超时或不可用时，不能据此断言菜单仍是英文。v0.8.2 及更早版本在新版 Codex 上可能混淆这两类情况。

v0.8.3 已适配新版设置与 Windows 菜单服务，并修复状态误报。使用旧版时，请在“设置与关于”检查更新，或从 [最新 Release](https://github.com/shibaweidu/codex-desktop-zh/releases/latest) 下载 v0.8.3 或更新版本。

## 界面中文，菜单还有英文

通过工具“汉化并启动”，不要从普通快捷方式复用旧进程。保存工作后可确认“关闭并汉化重启”。v0.8.3 起的 Windows 工具中，已有可验证接口的会话可以尝试“修复并验证（不重启）”。

若日志中列出新英文标签，提交 Codex 版本、平台、对应菜单截图和脱敏后的 `menu.detail`。插件商店中的第三方标题、作者说明、代码及用户内容不属于菜单翻译字典覆盖范围。

## 工具关闭后会变回英文吗？

不会立即恢复。`localeOverride` 由 Codex 保存，菜单翻译和运行时配色则依赖当前进程；Codex 退出、完整页面刷新或更新后，可能需要再通过工具应用。

## 无法发现客户端

Windows 便携版请手动选择可执行文件；macOS 请手动选择 `.app`。检查是否下载了与本机处理器匹配的工具包。Windows ARM64 尚未经过完整验证。

## 下载完成，但 Codex 更新失败

先保存工作并退出 Codex，再重试系统安装。确认当前登录账户和目标安装类型，查看日志中具体系统错误码；工具会复核实际注册版本，不把下载完成当作更新成功。不要直接删除受系统保护的安装目录。

## 如何提交有效反馈

打开 [问题模板](https://github.com/shibaweidu/codex-desktop-zh/issues/new/choose)，提供：系统及架构、工具版本、Codex 版本与安装类型、复现步骤、对应状态截图和脱敏日志。分享前检查路径、用户名、项目名称和其他私人信息。安全问题请按 [安全说明](../SECURITY.md) 私下报告。
