### 汉化兼容修复

- 接入新版 Codex 设置服务，保留旧接口兼容；旧动态配置不再作为判断汉化能否成功的唯一条件。
- 新版 Windows 使用页面菜单服务翻译并检查菜单，补充“在聊天与标签页之间切换”，保留命令、快捷键和启用状态。
- 按可见界面控件验证语言，排除聊天正文，避免嵌套成功状态和中英文混合界面造成误报；接口不可用与真实遗漏分开记录。
- Windows 新增不重启修复，只使用经过进程身份和监听端口归属验证的回环接口；不关闭、刷新当前会话，也不回退到会刷新的旧设置流程。没有可验证接口时，仍需保存工作后确认关闭重启。

### 验证与限制

Windows 本机 Codex `26.1120.6357.0` 验收：8 个中文界面标签、0 个英文标签；当前菜单检查 46 项，未覆盖列表为空。汉化脚本 22 项、主题脚本 21 项以及工作台、包验证、隔离关闭测试通过。Windows 与 macOS 两种架构均通过 CI 构建和测试。

Mac 上真实 Codex 汉化尚待实机人工验收；CI 构建成功不等于所有版本均兼容。Mac 包采用 ad-hoc 签名，未经 Developer ID 公证，首次打开可能需要右键“打开”或在“隐私与安全性”确认来源后选择“仍要打开”。

已有用户可在“设置与关于 > 检查更新”下载校验后覆盖更新工具；此更新不会关闭 Codex。“下载 Codex”则更新客户端，安装前请保存工作并按提示退出。
