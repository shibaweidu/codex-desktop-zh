## Codex 汉化增强工具 v0.8.2

本次主要改善 Windows Codex 客户端下载与更新。支持中文界面、运行时菜单翻译、客户端下载、主题配色及日志诊断；这是社区工具，不是 OpenAI 官方产品。

### 下载

- [Windows 10/11 x64 EXE](https://github.com/shibaweidu/codex-desktop-zh/releases/download/v0.8.2/Codex-Zh-Launcher-Windows-x64.exe)
- [macOS Apple Silicon ZIP](https://github.com/shibaweidu/codex-desktop-zh/releases/download/v0.8.2/Codex-Zh-Launcher-macOS-arm64.zip)
- [macOS Intel ZIP](https://github.com/shibaweidu/codex-desktop-zh/releases/download/v0.8.2/Codex-Zh-Launcher-macOS-x64.zip)
- [SHA256SUMS.txt](https://github.com/shibaweidu/codex-desktop-zh/releases/download/v0.8.2/SHA256SUMS.txt)

### 改进

- Windows 优先直连社区镜像，失败后切换下载入口，显示下载速率。
- 支持中断后续传与已校验缓存复用，减少重复下载。
- 系统部署后检查当前账户实际注册的 Codex 版本，失败时保留 Windows 返回码和错误。
- 安装前继续校验大小、SHA-256、签名、发布者与 MSIX 包身份。

### 安装与升级

Windows 直接运行 EXE；已有工具可在“设置与关于”检查更新。macOS 选择与芯片匹配的 ZIP，解压后放入 Applications。Mac 包采用 ad-hoc 签名，尚无 Developer ID 公证，可能需要右键打开或在“隐私与安全性”确认来源后选择“仍要打开”。

“下载 Codex”更新的是 Codex 客户端，与汉化工具自身更新不同。Windows 部署客户端前请保存工作并退出 Codex，便携版通过原渠道更新。

### 兼容性说明

新版 Codex 可能改变设置与菜单接口。v0.8.3 开发中的新版设置服务、Windows 菜单适配与不重启修复不包含在本次资产中。遇到“汉化未完全生效”，请查看语言和菜单的独立日志，按问题模板提交版本、截图与脱敏信息。
